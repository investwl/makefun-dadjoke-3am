A dad joke told out loud at the table. An AI agent drafts several lines, scores them by the brief, and writes
the winner to `/output/entry.txt`. It ships:

> I asked the librarian if the library had books on paranoia. She whispered, 'They're right behind you.'

## Run it

```sh
python3 main.py
```
